### 🌟 Codename: *Steady by Design*

🧭 **53 个 PR · 13 位贡献者 · 5 天** — **从 Prototype 开始创作，浏览每一页幻灯片
时预览与备注保持同步，导出可编辑的 PowerPoint 文件并保留字体与换行。我们还修复了
生成的作品可能打开后是一片空白的问题。** 0.19 把「能做什么」这份清单填满了，
0.20.0 让清单上的每一项都真正立得住——从在 Home 的第一次点击，到最后交出去的文件。

## 🔥 亮点

- 🧪 **Home 从大多数人真正的起点开始：做一个原型。** 新打开的输入框默认停在
  Prototype，创建类型也变成一份由产品定义的固定清单——Prototype、Slide deck、
  Image、Document、HyperFrames、Website clone、Video、Audio、Live artifact、
  WebGL——不再随着装了哪些插件而变动。Landing / 营销、仪表盘、移动应用、线框图、
  应用、开发者工具、品牌 / 设计、文档 / 报告这些场景始终在 Prototype 下，且各语言
  一致；Community 的筛选也优先展示原型。 (#6914, #6975, #6906, #6980)

- 🎞️ **可编辑的 PowerPoint 保留你确认过的设计。** 导入的 Google Fonts 会随文件
  一起带走，你排好的换行不会在 PowerPoint 或 WPS 里重新回流，分层的幻灯片背景也
  能完整保留。source 模式导出在各开发运行时下恢复正常，标题里含 `$` 替换序列时
  也会原样导出，不再丢字符。 (#6840, #6845, #6921, #6947)

- 🖼️ **点缩略图就会跳到它显示的那一页。** 缩略图、主舞台、页码、演讲者备注和
  上一页 / 下一页控件现在作为一个整体联动——新旧两种 deck 都是如此——不会再出现
  侧栏翻页而主画面停在第一页的情况。缩略图保持幻灯片的真实比例，从 Community
  remix 一份 deck 后也能立刻看到可用的预览。 (#6950, #7095, #6996)

- 🩹 **生成的作品不再打开后是一片空白。** 切换文件、在 Code/Preview 之间切换、
  或在项目之间跳转时，Chromium 中止了已保留的预览导航，会留下一块永久白屏。现在
  预览会在这些切换中保持挂载并可直接复用，导航被中止时能自行恢复，字体也会正常
  加载，而不是退化成一个裸页面。 (#7128, #7055, #7007)

- 🎬 **HyperFrames 从应用里渲染视频，不再依赖你的 npm 缓存。** 视频作品现在通过
  Open Design 生成脚手架，并使用与 daemon 一起打包、版本固定的 HyperFrames
  runtime 渲染，用户 npm 缓存里一个过期的原生产物不会再让生成失败；Windows 打包
  版本也能正确带上它。 (#7030, #7132)

- 🌐 **Website Clone 直接用你已经装好的浏览器。** 克隆网站过去要往每个生成的项目
  里装 Playwright，一装几分钟还经常失败。现在它通过一个隔离的临时 profile 驱动
  已安装的 Chrome、Edge 或 Chromium，不会改动你的项目；从界面发起还是用 `od`
  在没有客户端窗口时发起，行为一致。 (#7000, #7066)

- 🧑‍🤝‍🧑 **Workspace 抖一下，不会把你的项目一起带走。** 云端目录短暂不可达时，
  已经在本机的文件仍然可以编辑、运行和分享；新受邀的成员不必等整个共享项目传输
  完就能打开；公开的文件分享在 daemon 重启后依然有效；你上次所在的 workspace
  也还是你回来时的那个。 (#7027, #6989, #7002, #7067)

- ⚡ **刷新一次长会话，不用为整段历史重新买单。** 数分钟级别的会话仍然实时流式
  输出 thinking 与正文，但记录改为按批次追加写入：重新加载保持流畅，进行中的运行
  能干净地重建，已结束的对话也不会再累积越来越高的重写成本。 (#6952)

- 🧹 **Open Design 的 anti-slop 检查可以在任何地方跑。** 应用内把关作品质量的
  linter 现在也是 `od lint`。指向一个文件或从 stdin 读入，设定失败阈值，就能拿到
  可读或 JSON 格式的结果，全程不需要启动模型——无界面 agent 和 CI 因此能在导出前
  就拦下敷衍的产出。 (#6959)

- 🛑 **失败的运行不再看起来像成功。** 反复出现的 OpenCode shell 报错——包括过去被
  当成「工具已完成」放过去的 PowerShell 失败——现在会触达循环守卫，Open Design
  可以提醒、停下并保留真实错误，而不是以一个绿色的结果收尾。超出上下文窗口的
  Claude 运行也会被明确指出，而不是报成笼统的执行失败。 (#6933, #7044)

- 🖼️ **被拒绝的图片会直说是被拒绝了。** 内容安全策略拒绝一次图片请求时，回复会
  明确说明，并指向你真正可以调整的提示词或参考图——而不是让你去等一次永远不会
  恢复的「服务故障」。 (#6993)

- 🌍 **切换 AMR 环境会带着整个应用一起走。** 余额、Workspace 上下文、升级入口和
  设置里的跳转目标现在都跟随你选择的 profile——prod、test 或 feature-test——且
  不需要重启；没有映射的目标会安全失败，而不是悄悄打开错误的环境。 (#6991)

- 👤 **最近项目看起来像你的工作区，而不是一份匿名列表。** 你自己的项目会显示登录
  账号的名字和头像，而不是笼统的「Me」；列表行的更多菜单在靠近屏幕底部时会向上
  展开，让包括删除在内的每个操作都够得着。 (#6857, #6971)

- 🛡️ **BYOK 媒体下载在你的机器周围划出更硬的边界。** 外部供应商返回的图片和视频
  URL 不能再把 daemon 引回 localhost，包括通过 DNS 手法绕行。你主动配置的本地
  供应商网关照常可用；不受信任的素材响应不再享有同样的权限。 (#6072)

## ✨ 新增

### 🧠 Agent、运行时与自动化

- `od lint <file.html|->` 把作品质量检查带给无界面 agent、脚本和 CI，支持配置失败
  阈值、stdin 输入和机器可读的 JSON 输出。 (#6959)
- Open Design 交付作品之后可以出现一份简短的体验调研，预设选项之外还提供「其他」
  这一项。 (#6999, #7117)

### 🏠 Home、Community 与官网

- DeepSeek Harness 设计合集新增六个精选插件、插画封面，以及更完整的从安装到设计的
  教程。 (#6903, #6943, #6945)
- 官网发布 0.19.1、提供安装包直接下载，新增香港活动回顾，并在 Events 页突出上海
  场次。 (#6901, #6982)
- 各语言 README 更新了产品导览，并加上飞书社群入口。 (#6922, #6946)

## 🔁 变更

- 新打开的 Home 输入框默认创建类型为 Prototype；已保存的选择或明确的跳转仍然优先。
  Prototype 场景不再依赖已安装的插件目录。 (#6975, #6914)
- 新客户端默认开启完成提示音和桌面通知。 (#7038)
- 结果摘要只列出真正交付的文件。 (#7006)
- 纯媒体模型不再出现在聊天的模型选择器里。 (#7123)
- 0.19.2 引入的结构化 design-system runtime 已回滚，连同其 CLI 与 API 表面一并
  移除。在该工作流重做期间，design system 回到此前的 manifest 与 prompt 行为。
  (#7110)

## 🐛 修复

### 🎨 幻灯片、导出与预览

- 可编辑 PPTX 导出会嵌入兼容的导入字体，保留作者排好的换行和分层幻灯片背景；
  运行时以不同模块形态暴露导出器时，source 模式导出不再失败。 (#6840, #6845,
  #6921)
- 标题中含替换序列时，PDF、图片和示例导出保持原文。 (#6947)
- 缩略图、主舞台、页码、演讲者备注和上一页 / 下一页控件在新旧幻灯片结构下保持
  同步，缩略图也保持幻灯片的真实比例。 (#6950, #7095)
- HTML 与幻灯片预览能挺过文件标签页、Code/Preview 和项目切换，导航被中止后可以
  恢复，字体也会正常加载。 (#7128, #7055)
- Community 的 deck remix 预览稳定可用，HTML 卡片缩略图不再被二次缩放，Home 示例
  区在重启后不再位移。 (#6996, #7007, #7037)

### 🧠 Agent、Workspace 与可靠性

- 长时间流式对话按增量持久化，从持久批次重新加载，并在运行结束时干净收尾。 (#6952)
- OpenCode 会保留失败的工具结果和非零退出码，让反复失败触达循环守卫，而不是伪装成
  成功的工作。 (#6933)
- Claude 提示词超长的失败会被明确归类。 (#7044)
- Vela 的图片安全拒绝会作为「拒绝」抵达客户端，而不是笼统的服务故障。 (#6993)
- 绑定 workspace 的项目在目录服务故障和新成员首次打开时仍然可用；workspace 权限
  从项目绑定推导；公开文件分享和上次选中的 workspace 都能挺过 daemon 重启。
  (#7027, #6989, #7002, #7067)
- AMR 余额、Workspace 上下文、升级入口和设置跳转跟随所选环境；该环境没有可信目标
  时会安全停下。 (#6991)
- 执行诊断保留运行时用量归因。 (#7076)
- Trace 对象权限改由 Vela 统一裁定。 (#6986)
- 外部 BYOK 素材 URL 无法解析到回环地址，同时明确配置的本地供应商端点照常可用。
  (#6072)
- HyperFrames 的脚手架与渲染不再依赖环境中的 `npx` 安装，Windows 打包按平台声明
  原生依赖。 (#7030, #7132)
- Website Clone 会启动系统浏览器，而不是往每个生成的项目里安装 Playwright；界面
  与 `od` 两条路径一致。 (#7000, #7066)

### 🖥️ Home、插件与界面细节

- 最近项目卡片显示登录账号身份，列表行菜单会选择让所有操作都留在屏幕内的展开方向。
  (#6857, #6971)
- 社区插件详情页可以滚动，其弹窗会遮住完整的应用外壳——包括账号和 GitHub 控件——
  而不是让它们浮在上面。 (#7070, #6912)
- Message Center 的关闭按钮回来了。 (#6992)
- 项目「可更新」指示恢复正常。 (#7004)
- 官网不再重复展示同一段套餐能力。 (#6913)
