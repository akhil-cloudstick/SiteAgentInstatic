# CMS-New-UI — review images

The **75 MMSBUILD design assets** (approved masters, repo-aligned vN, existing
captures, existing-vs-redesign comparisons, and early direction explorations)
live here, copied from the design handoff and committed to the repo.

They're referenced from [`../CMS-New-ui.md`](../CMS-New-ui.md) →
**"Approved reference mocks"** (embedded/linked per screen) and used for the
**"Bug log"** and **"Implementation status"** review.

## Naming scheme (as delivered)
`<nn>-<screen>-<theme|existing|comparison>-<approved|repo-aligned|direction>-<state>[-vN].png`

- Build targets are the latest `-repo-aligned-*-vN` / `*-approved-*` masters.
- Site screen files are prefixed `01-site-*` (approved **light** only — dark is
  the guide's delivery gap).

## Adding review screenshots
Save build-vs-mock comparison shots here as
`<nn>-<screen>-<theme>-<state>.png` (e.g. `02-content-light-seo-bug.png`) and
reference them from the **Bug log** in `../CMS-New-ui.md`.
